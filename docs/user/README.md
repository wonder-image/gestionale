# Guida al gestionale

Questa guida spiega, passo per passo, come usare il pannello del tuo sito: il
catalogo, il magazzino, i clienti, gli ordini e tutto il resto.

Ogni pagina della guida inizia dicendo se quello che descrive è **incluso**,
**da attivare su richiesta** oppure **configurato da Wonder Image**.

Il gestionale è in costruzione: la guida cresce insieme a lui.
