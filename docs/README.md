# Wonder Gestionale

Modulo per `wonder-image/app` che porta catalogo, magazzino, anagrafiche,
vendite, fatturazione e spedizioni dentro il backend di un sito Wonder.

Il modulo è **predisposto al massimo**: le funzionalità esistono già nel codice
e si sbloccano dal pannello, una alla volta, quando servono. Un negozio piccolo
e un distributore usano lo stesso gestionale con due pannelli molto diversi.

## Da dove cominciare

| Se vuoi | Vai a |
|---|---|
| installare il modulo su un sito | [Installazione](guida-introduttiva/installazione.md) |

## Stato

Il modulo è in costruzione: la versione `1.0.0` arriva quando il nucleo è
completo. Le decisioni di architettura e i piani di lavoro stanno in
`docs/superpowers/`, fuori da questa guida.
